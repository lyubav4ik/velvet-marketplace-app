# SESSION — velvet-marketplace-app

## Статус
Приложение в стадии прототипирования блоков. Кода серверной части пока нет.

## Роли (договорённость с пользователем)
- Пользователь сама создаёт сайты и страницы на портале через UI.
- Задача приложения — ТОЛЬКО регистрация кастомных блоков в конструкторе (`landing.repo.register`), типы блока `["page","store"]`, чтобы работали и на обычных сайтах, и на магазинах.

## Что есть
- `prototype/original-main.html` — копия главной страницы из прототипа «вельвет» (velour-marketplace-app/prototype-pages/01-главная/code.html).
- `prototype/blocks/` — нарезка главной на 6 блоков, 1 html = 1 визуальный блок:
  - `01-header.html` — фиксированная шапка (лого MAISON, меню, иконки)
  - `02-hero.html` — полноэкранный баннер с CTA
  - `03-categories.html` — сетка 3 категории с hover-эффектами
  - `04-new-arrivals.html` — карточки товаров (4 шт, горизонтальный скролл на мобиле)
  - `05-brand-story.html` — фото + текст о бренде
  - `06-footer.html` — подвал
- Нарезка чисто визуальная (для согласования разделения), НЕ зарегистрирована в Битрикс24.
- `WORKLOG-BLOCKS.md` — зафиксированный процесс регистрации блока в конструкторе (проверенный цикл).
